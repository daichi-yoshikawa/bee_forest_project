１．「針葉樹以外面積」について：
針葉樹・竹以外の環境データである混合林、広葉樹、果樹園、畑、公園、住宅緑地を合わせた
「人工的なものも含まれるが多様性が比較的ある緑地」の面積に相当する。
環境データが被っている部分の面積は重複してカウントしないようにしている。

２．「疑似自然率」について：
「(針葉樹以外面積 - 針葉樹・竹面積) / 巣箱周辺面積」として計算している。
要するに、巣箱周辺で、針葉樹以外の植物がどれだけ針葉樹を上回って存在しがちであるか、を表す。
負の値(ゼロより小さい値)も取り得る。この場合、針葉樹が支配的にそのエリアを覆っていることを意味する。
逆に正の値の場合は、「針葉樹がそのエリアに含まれているかもしれないが、それをその他の
植物がどれだけカバーできているか」を表す指標となっている（と大地が思っている）。


３．結論:
半径500, 1000, 2000mエリアのいずれにおいても、
(a) 針葉樹率が増えれば増えるほど営巣率が低くなる傾向がある。
　　-> 針葉樹率と営巣率の間に弱い負の相関(およそ-0.36)がある。
    -> p値が0.018~0.022程度で、優位な差がある。
(b) (a)とほぼ同義であるが、針葉樹率が高ければ高いほど営巣有となる傾向がある。
　　-> 信用樹立と営巣有無の間に弱い負の相関(およそ-0.40)がある。
　　-> p値が0.006~0.009程度で、優位な差がある。
(c) 疑似自然率が高いほど、営巣有となる傾向がある。
　　-> 疑似自然率と営巣有無の間に弱い正の相関(およそ0.35)がある。
　　-> p値が0.012-0.023程度で、優位な差がある。

４．p値の使い方
以下、結論(c)を例にとってp値を説明する。
奈良2021巣箱500m営巣率相関.xlsxファイルによると、疑似自然率と営巣有無との相関係数は
0.3546...でありp値は0.0229...である。
これは以下のように解釈できる。

帰無仮説を「疑似自然率と営巣率に相関はない」、
対立仮説を「いやいや、弱いけど正の相関ありますよ」としてt検定をしたところ、
p値が0.0229となった。
これにより、帰無仮説が本当に正しいとした場合に今回のような検証結果・計算結果となるような
確率は0.0229,つまり2.29%程度であるということが分かった。
ということは、帰無仮説が正しいとは考え難く、疑似自然率と営巣率に相関がないとは言えないことが
統計的に裏付けられた。
